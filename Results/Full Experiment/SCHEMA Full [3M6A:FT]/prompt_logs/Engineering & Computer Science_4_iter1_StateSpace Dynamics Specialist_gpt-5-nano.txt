1) Minimal pseudocode (two-step node→hyperedge→node, with learnable W_e, exponents, optional attention):
function HyperedgeMP(X, H, W_e, Θ_e, Θ_n, α,β,γ,δ, use_att=False):
  # H: sparse N×M incidence (0/1); X: N×d
  d_v = max( H @ (W_e.diag() @ ones(M)), eps )
  d_e = max( H.T @ ones(N), eps )
  # node→hyperedge aggregate
  Xn = D_v^{-β} X           # scale rows by degree^(-β)
  E_agg = H.T @ Xn         # M×d
  E = D_e^{-α} * (E_agg * W_e[:,None])   # elementwise scale by W_e and degree^(-α)
  E = E @ Θ_e              # linear/MLP map
  if use_att:
    att = softmax( (H.T @ (X @ Θ_att)) , dim=1 )  # M×1 or M×k
    E = E * att
  # hyperedge→node broadcast
  Eb = D_e^{-δ} * (E * W_e[:,None])
  Xb = H @ Eb              # N×d
  Xb = D_v^{-γ} * Xb
  X_out = σ( Xb @ Θ_n ) + X  # residual
  return X_out, E

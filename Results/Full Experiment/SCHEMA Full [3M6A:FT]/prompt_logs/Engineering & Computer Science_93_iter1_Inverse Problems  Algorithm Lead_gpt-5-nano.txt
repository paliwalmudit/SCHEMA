1) Discrete forward/adjoint operator (compact form)
- Continuous: p0(r)=Γ(r)μa(r)Φ(r); acoustic propagation solves (∇·∇ − c(r)−2 ∂^2/∂t^2 + A[·]) p(r,t) = ∂t (p0(r)δ(t)).

- Adjoint: F^T = A^T · M^T · P^T where A^T is implemented by time‑reversed propagation with identical absorbing boundary/PML and the same c(r)/attenuation model (ensures adjoint identity). c(r) is discretized on the same octree/grid used for A (piecewise constant per leaf) so operator is self‑consistent.

2) Matrix‑free kernels and precision policy (summary)
- Implementation: forward/adjoint via explicit time‑stepping (staggered FD or k‑space pseudo‑spectral) on local octree blocks with PML absorbing layers. Pseudocode: time‑step loop computing spatial Laplacian/derivatives → apply heterogeneous c(r) factors → local attenuation update → accumulate sensor integrals via compact support kernel → convolve with precomputed low‑rank EIR. The adjoint runs the time‑reversed loop with identical halo exchange pattern.  
- Per‑point cost (approx): 80–150 flops per grid/point/time‑step for 2nd–4th order stencils including attenuation and aperture integration; memory per point: 4–6 floats (pressure, velocity components, c(r) tag, temp buffers). Final per‑point numbers will be microbenchmarked.  
- Precision: store geometry and parameters in FP32; compute spatial derivatives and local updates in FP16 where stencil stability allows but accumulate time‑series and global reductions in FP32. - Inner CG stopping rule (practical mapping): choose relative tolerance η_k = min(0.1, 0.1·||r^{outer}_k||) for early iterations, tighten to η_k = 0.01·||r^{outer}_k|| when ADMM primal residual falls below target.

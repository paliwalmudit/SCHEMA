1) Aggregation model and basic definitions
- Let N = {1,…,n} index atomic feature dissimilarities f = (f1,…,fn) with fj(x,x') ≥ 0. Aggregate distance D_mu(f) = C_mu(f), the (discrete) Choquet integral with respect to a capacity mu: 0 = mu(∅) ≤ mu(A) ≤ mu(N) (monotone), typically normalized mu(N)=1 (or scaled).
- Computation: order f_(1) ≤ … ≤ f_(n) and let S_i = {indices with f ≥ f_(i)}. Then
  C_mu(f) = ∑_{i=1}^n (f_(i) − f_(i-1)) mu(S_i), f_(0)=0.
- Möbius parameterization: there is a unique Möbius transform m: 2^N → R with mu(A)=Σ_{B⊆A} m(B). The Choquet integral is linear in m:
  C_mu(f) = Σ_{A⊆N} m(A) min_{i∈A} f_i.

2) Families of measures to learn and constraints
- Monotone capacity constraints (linear): for all A⊆N and j∉A, mu(A∪{j}) − mu(A) ≥ 0. In Möbius form these are linear inequalities in m(B) (since mu = sum_{B⊆·} m(B)). Enforce mu(∅)=0 and mu(N)=1 (linear equality).
- k-additive family: restrict m(A)=0 for |A|>k. This reduces parameters to p = Σ_{r=1}^k C(n,r) and keeps linearity of C_mu in free parameters.
- Sparsity priors: add L1 or group-L1 penalties on m(A) (or on families by cardinality) to encourage few nonzero subset weights.
- Interaction priors: enforce sign constraints on interaction indices (e.g., force nonnegative interactions or bound their magnitude) by linear constraints expressed via mu differences or via Möbius aggregation.
- Interpretability constraint: require monotone marginal contributions mu(A∪{i})−mu(A) ≥ 0 and optionally nonnegativity of some m(A) for semantic clarity (positive synergy vs redundancy).

3) Identifiability and sample complexity
- The Choquet integral is linear in the Möbius parameters; identifiability requires that the observed training set of vectors f^(t) allow the matrix with columns {min_{i∈A} f^(t)_i}_A to be full column-rank for the chosen parameter set. Thus the number of effectively independent training conditions must be ≥ number of free parameters p. If features are collinear or f vectors lack variety, mu is not identifiable without stronger priors (k-additivity, sparsity).
- Recommendation: choose k small (k=2 or 3) when n moderate-to-large so p remains tractable and identifiability achievable with realistic sample sizes.

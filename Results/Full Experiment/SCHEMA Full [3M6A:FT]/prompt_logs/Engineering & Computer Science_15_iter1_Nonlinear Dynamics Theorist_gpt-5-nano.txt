- Adopt simulation-based power analyses tied to pilot variances for FTLE and RQA determinism. Use hierarchical mixed-model simulations (random heart effect + epoch residuals) with 1,000–5,000 replicates to empirically estimate power under candidate MDEs.
- Tools: R simr or Bayesian design analyses; report power curves across N per perturbation and across preparations. Target 0.8 power at α = 0.05 (two-sided) for the primary outcomes.

2) Absolute minimum detectable effects (MDEs)
- Anchor FTLE MDE to a physiologically meaningful 0.02–0.05 1/s change (reflecting a 10–25% shift in predictability horizon for typical cycle lengths). Anchor RQA determinism MDE to 5–10 percentage points. Define these as absolute units to guide sample-size decisions.

3) Aggregation method and decision rules
- Recommend hierarchical Bayesian pooling with weakly informative priors; pre-register decision rules: claim effects if posterior probability of benefit ≥ 0.975 and median effect ≥ pre-registered MDE. If results conflict with a meta-analytic Fisher/Hedges approach, report both with sensitivity analyses and prefer the Bayesian conclusion unless priors are demonstrably mis-specified.

4) Sensitivity analysis protocol for algorithmic thresholds
- Run parameter sweeps across RR 1–5%, neighbor radius 1–5% attractor diameter, and FNN thresholds 0.01–0.05 with AMI lags up to 1.5× median CL. Define canonical presets by requiring metric stability: changes across plausible ranges <10%. Distinguish short epochs (fewer cycles) from long epochs with tailored defaults (e.g., short: RR 3–5%, radius 3–5%, FNN 0.05; long: RR 1–2%, radius 1–2%, FNN 0.02–0.04).

5) Canonical, versioned reference implementations
- Publish high-level, versioned reference implementations (pseudo-code or library calls) for AMI, FNN, Rosenstein LTLE, and RQA, specifying Euclidean distance, standard L2 norms, and exact scaling and unit conventions. Include sampling-rate mappings to physiologic timescales and a clearly documented norm for attractor diameter.

6) Pre-registration and preprocessing specifications
- Pre-register: (i) sampling rates (ECG ≥1 kHz, intracellular ≥2 kHz), (ii) bandpass filters (ECG 0.5–300 Hz, intracellular 0.1–1000 Hz), (iii) notch criteria (50/60 Hz only when SNR >6 dB), (iv) artifact rules (z-score/kurtosis thresholds), and (v) interpolation vs masking rules (gaps ≤200 ms ok only for visualization).

7) Reproducible model training protocol and CI
- Hyperparameters: LR 1e-4, batch 32, up to 100 epochs, early stopping on mechanistic metrics; ensemble of 5 seeds. Baseline v0.1 checkpoint required. Implement CI tests that reproduce tiny end-to-end runs and verify bootstrap reproducibility within 10%.

8) Synthetic-data governance and validation
- Maintain a held-out real-validation set; require synthetic augmentations to keep Δλ ≤5%, ΔDet ≤10%, and CL within ±2% relative to matched real epochs; mandate independent sign-off and adversarial checks.

9) Causal mapping validation
- Use permutation tests with FDR correction for latent–physiology mappings; require a minimal in‑vitro perturbation set to confirm predicted causal effects.

10) CI/test coverage and escalation
- Mandate a minimal CI suite with numeric tolerances, regression tests for surrogate outputs, and an escalation workflow for any regression or data-quality anomaly.

These deliverables should be codified into preregistration, SOPs, and a compact metrics-parameters reference to accelerate implementation.

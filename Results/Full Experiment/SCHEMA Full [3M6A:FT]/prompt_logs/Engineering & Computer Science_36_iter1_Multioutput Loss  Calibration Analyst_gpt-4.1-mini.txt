1) Cross-talk modules (closed-form)
- Gated-additive message for branch i receiving from branches j != i:
  m_ij = P_v( f_j )  (low-rank projector P_v: R^D -> R^r)
  M_i = (1/(N-1)) sum_{j!=i} W_m m_ij
  g_i = sigmoid( W_g [f_i; pooled(M_i)] + b_g )  (per-channel or per-dim gate)
  f_i' = f_i + g_i * U( M_i )  (residual update; U: projection R^r -> R^D)
- Gated multi-head cross-attention (H heads, bottleneck r per head):
  For head h: Q_i^h = Q_h(f_i) in R^{r}, K_j^h = K_h(f_j), V_j^h = V_h(f_j)

1) Prototype-guided affinity — math and pseudocode (compact)
- Notation: F ∈ R^{H×W×C} feature map, f_i ∈ R^C pixel feature, confident seed sets S_k for class k. Prototypes P_k ∈ R^C.
- Prototype update (online EMA from confident pixels):
  P_k ← normalize( β P_k + (1−β) mean_{i∈S_k} f_i ), 0<β<1.
- Prototype similarity: sim(u,v)=u·v / (||u|| ||v||).
- Affinity score between pixels i,j:
  A_ij = λ · sim(f_i,f_j) + (1−λ) · max_k [ sim(f_i,P_k) · sim(f_j,P_k) ].
- Affinity loss (contrastive form):
  L_aff = − 1/|S+| ∑_{(i,j)∈S+} log σ(A_ij/τ) − 1/|S−| ∑_{(i,j)∈S−} log (1−σ(A_ij/τ)),
  where S+ are same-class confident pairs, S− are different-class or boundary pairs, τ temperature, σ sigmoid.
- Propagation (normalized random-walk):
  W_ij = exp(A_ij); D_ii = ∑_j W_ij; T = D^{-1}W; Q^{(t+1)} = α T^T Q^{(t)} + (1−α) S_seed with S_seed initial seed one-hot/soft maps. Iterate T steps, produce pseudo-labels = argmax_k Q_k and per-pixel confidence = max_k Q_k.

Pseudocode (high-level)
1. Generate CAM/box/point seeds S_seed.
2. Extract F, initialize prototypes P_k from S_seed.
3. For epochs:
   a. Sample local pixel pairs, compute L_aff, update affinity encoder.
   b. Update P_k via EMA from current confident predictions.
   c. Build W, propagate Q via T iterations.
   d. Form pseudo-labels using confidence thresholds; train segmentation head with seed/pseudo cross-entropy + consistency losses.
4. Maintain EMA teacher: θ_teacher ← α θ_teacher + (1−α) θ_student each optimizer step.

1) Prototype-guided affinity — math and pseudocode (compact)
- Notation: F ∈ R^{H×W×C} feature map, f_i ∈ R^C pixel feature, confident seed sets S_k for class k. Prototypes P_k ∈ R^C.
- Prototype update (online EMA from confident pixels):
  P_k ← normalize( β P_k + (1−β) mean_{i∈S_k} f_i ), 0<β<1.
- Prototype similarity: sim(u,v)=u·v / (||u|| ||v||).
- Affinity score between pixels i,j:
  A_ij = λ · sim(f_i,f_j) + (1−λ) · max_k [ sim(f_i,P_k) · sim(f_j,P_k) ].
- Affinity loss (contrastive form):
  L_aff = − 1/|S+| ∑_{(i,j)∈S+} log σ(A_ij/τ) − 1/|S−| ∑_{(i,j)∈S−} log (1−σ(A_ij/τ)),
  where S+ are same-class confident pairs, S− are different-class or boundary pairs, τ temperature, σ sigmoid.
- Propagation (normalized random-walk):
  W_ij = exp(A_ij); D_ii = ∑_j W_ij; T = D^{-1}W; Q^{(t+1)} = α T^T Q^{(t)} + (1−α) S_seed with S_seed initial seed one-hot/soft maps. Iterate T steps, produce pseudo-labels = argmax_k Q_k and per-pixel confidence = max_k Q_k.

Pseudocode (high-level)
1. Generate CAM/box/point seeds S_seed.
2. Extract F, initialize prototypes P_k from S_seed.
3. For epochs:
   a. Sample local pixel pairs, compute L_aff, update affinity encoder.
   b. Update P_k via EMA from current confident predictions.
   c. Build W, propagate Q via T iterations.
   d. Form pseudo-labels using confidence thresholds; train segmentation head with seed/pseudo cross-entropy + consistency losses.
4. Maintain EMA teacher: θ_teacher ← α θ_teacher + (1−α) θ_student each optimizer step.

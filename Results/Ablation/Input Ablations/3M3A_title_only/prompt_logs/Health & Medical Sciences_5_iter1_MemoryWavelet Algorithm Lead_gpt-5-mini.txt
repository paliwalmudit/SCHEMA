Architecture overview:
- Backbone encoder-decoder (lightweight UNet/HRNet variant) as the spatial feature extractor producing multi-scale feature maps. Use depthwise separable convolutions to reduce cost.

- Memory bank: multi-scale, multi-frequency key-value store. For each scale and frequency band store compressed keys (projected features) and values (feature maps). Retrieval uses scaled dot-product attention to fuse long-range context into current features.

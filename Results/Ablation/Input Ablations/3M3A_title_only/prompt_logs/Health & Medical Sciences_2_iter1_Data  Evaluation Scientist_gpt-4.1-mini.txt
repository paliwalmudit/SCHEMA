1) Posterior fusion (diagonal Gaussian features)
- Given encoder feature Gaussian N(μ_e, Σ_e) and decoder prior N(μ_d, Σ_d) with diagonal Σ (elementwise variances v_e, v_d), posterior precision and mean are:
  Λ_post = Λ_e + Λ_d where Λ_e = 1 / v_e, Λ_d = 1 / v_d (elementwise).
  v_post = 1 / (1/v_e + 1/v_d)
  μ_post = v_post * (μ_e / v_e + μ_d / v_d)  (elementwise multiplication/division).
- This is numerically stable because we operate via precisions; implement with safe clamps on v_e,v_d before inversion.

2) Low-rank + diagonal bottleneck extension (guarantee PD)
- Parametrize covariance as Σ = D + U U^T with D = diag(d)>0 and U ∈ R^{C×r}, r ≪ C.
- Use Woodbury to obtain precision:
  Σ^{-1} = D^{-1} - D^{-1} U (I_r + U^T D^{-1} U)^{-1} U^T D^{-1}.
- For two such covariances Σ_e, Σ_d compute Λ_post = Σ_e^{-1} + Σ_d^{-1} via above formula; obtain Σ_post by solving linear system (e.g., Cholesky on Λ_post) to produce μ_post = Λ_post^{-1}(Λ_e μ_e + Λ_d μ_d). Keep r small (2–32) to remain tractable.

3) Multi-class segmentation NLL under Gaussian logits (MC marginalization, stable)
- For pixel with true class y, approximate p(y|x) = E_{z∼N(m,Σ)}[softmax_y(z)] via K samples z^(k).
- Compute per-sample log-prob: lp_k = z_y^(k) - logsumexp_j z_j^(k).
- Stable marginal log-prob: log p̂_y = logsumexp_k(lp_k) − log K.
- NLL = − log p̂_y.
- Bias/variance: log of averaged probabilities is biased (Jensen). Use K_train ∈ {2–8} (recommended 4) and K_eval ∈ {32–128}. Increasing K reduces bias at extra cost.

- Variable count_oob breaks simple symmetry only if we treat samples with zero/very-low OOB counts differently. To preserve coverage, require min_oob_count (recommend ≥5). 3) Streaming OOB aggregation pseudocode (core kernel)
- Inputs: n_samples n, number_of_trees T, X (contiguous), per-tree inbag_indices list, tree_predict(tree_index, X_batch) callback, batch_size B.
- Initialize sum_preds[n,(n_classes)] = 0, count_oob[n] = 0
- For start in range(0, n, B):
    Xb = X[start:start+B]
    For t in 0..T-1:
        preds = tree_predict(t, Xb)       # shape B x C
        inbag = inbag_indices[t] restricted to [start,start+B)
        mark = boolean mask of length B with True where sample IN bag
        For i in 0..B-1:
            If not mark[i]:
                sum_preds[start+i] += preds[i]
                count_oob[start+i] += 1
- After trees: for i where count_oob[i]>0: oob_pred[i] = sum_preds[i] / count_oob[i]
- Complexity: O(T * n) time overall; memory O(n * C) for sum_preds + O(n) for counts; batch reduces peak memory and enables cache-friendly updates.

- n_trees = 500 (stable OOB means), min_oob_count = 5, n_folds (CV+) = 5, batch_size = 8k–32k (tune by RAM; 8k safe), dtype default float32 for predictions (float64 option for quantile/residual computations or small-n regimes).

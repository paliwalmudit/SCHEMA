- Gated-attention update (primary): e_t = Enc(sign evidence); z_t = sigmoid(W_z[I_t; e_t]); u_t = LayerNorm(I_t + MultiHeadAttn(I_t, e_t)); I_{t+1} = (1 - z_t) ⊙ I_t + z_t ⊙ u_t.  
- Bayesian/Kalman-style update (alternative): I_{t+1} = I_t + K_t (e_t - H I_t) with K_t learned per-step gain.  
We will implement gated-attention for initial MVE and log alternatives for ablations.

2) Consistency loss L_consist and gradient routing
Define L_consist = λ_cons · (1 - cosine(Enc(O_t), I_t_target)) + λ_anchor · DriftPenalty(a_t, a_{t+1}), where cosine() ∈ [−1,1] is normalized to [0,1] by (1+cos)/2. Normalize each term to unit scale. Total training loss L = α·L_ce + β·L_consist + γ·L_habit (L_habit = KL/I_t stability term across contexts). Gradient routing schedule: for first N_warm epochs route L_consist gradients only to fusion network and adapter layers (stop-gradient on core LM), then gradually release fraction η of L_consist gradients to core LM (η ramp from 0 → 1 over epochs M) to avoid catastrophic overwriting.

3) Metric definitions and pre-registration
- Indexical Reliability (IR): IR = #(trials where model top-1 referent == ground-truth)/N_trials. Ties: use top-1; report top-k (k=3) as secondary. Cluster by session and compute 95% CIs via nonparametric bootstrap over session clusters. Primary test: mixed-effects logistic regression (fixed effect: condition; random intercepts: annotator, session); α=0.05 two-sided.  
- Interpretant Consistency (IC): IC = #(recurring-sign occurrences where ledger-predicted interpretant == model output across subsequent M occurrences)/#recurring-signs. Compute bootstrap CIs clustered by sign/session.  
- Rationale Fidelity (RF): mean human-rated score (0–2) normalized to [0,1]; aggregate by episode with bootstrap CIs.  
- Updateability (UR): UR(H) = P(model adopts human-correction for that sign within horizon H turns) estimated over episodes; H pre-register = 5 turns and next-session persistence. Statistical comparisons use logistic regression with cluster-robust SEs.

Tie/rule clarifications and thresholds (pre-registered): primary thresholds IR≥0.85, IC≥0.90, RF≥0.80, UR≥0.90 for mediated/full-stack condition; failure requires remediation.

4) Baselines and ablations (minimal matrix)
- Baselines: (A) Base LLM (no extra context), (B) Extended-context only (larger window), (C) Retrieval-only (no ledger persistence), (D) Adapter-only conditioning.  
- Ablations: (E) Ledger-only (persistence but no social mediation), (F) Provenance-only (signatures + provenance tags without consensus gating), (G) Random-anchor control, (H) Full stack (ledger + social mediation + normative manager). Compare all with pre-registered contrasts.

5) Adversary models, detection metrics, rollback policy
- Poisoning rates to test: 1%, 5%, 10%, 20% injected malicious corrections across episodes. Sybil profiles: 1–5 Sybils submitting coordinated malicious corrections. Detection metrics: TPR, FPR, Precision, Recall, and attack-success-rate. Remediation policy: compute provenance_confidence = weighted sum(rater_trust, recency, agreement); auto-block persistence when provenance_confidence < τ_block (pre-register τ_block = 0.6) or anomaly_score > τ_anom; require ≥2 independent authenticated raters for persistent updates in high-risk domains. Use cryptographic per-rater signatures with PKI and key-rotation; log practicality trade-offs and key-management procedures in security spec.

6) Human annotation protocol
Recruit annotators with linguistics or discourse experience; qualification: gold-set accuracy ≥80% on a 50-item test. Training: 2-hour rubric session with 20 exemplars per rating cell. Annotation tasks: for each interpretant entry annotate Correct Referent (binary), Anchor Sufficiency (0–2), Rationale Fidelity (0–2). IAA targets: Cohen’s κ ≥0.6 for Correct Referent, ≥0.5 for Rationale Fidelity; adjudication: majority vote, escalate unresolved cases to senior adjudicator. Privacy: informed consent, minimal PII, per-subject redaction; DP-sanitization for public release. Contingency: if IAA < targets, iterate training and increase exemplar set; re-run pilot.

7) Stress-testing, latency and partial-failure policy
Performance targets: retrieval latency single-entry <50ms, batch <200ms; ledger update throughput ≥1,000 ops/sec for MVE load. Consistency policy: strong consistency within-session (reads reflect latest committed interpretant) and eventual consistency across distributed replicas with tombstone/merge semantics; on partial failures fall back to read-only ledger with provenance flags and trigger human review for writes; rollbacks supported via versioned immutability.

8) Mapping Peirce triads to signals (operational diagnostics)
- Firstness: surface-sign priors measured by sign-form surprisal and distributional confidence.  
- Secondness: anchor alignment signals (anchor reliability, causal role agreement).  
- Thirdness: interpretant habit measured by IC and UR; diagnostics include sensitivity of referent selection to removal of anchor cues (ablation test) and resistance to mirror hallucinations under adversarial exposure.

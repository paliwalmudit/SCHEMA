- Factorized joint critic (recommended scalable variant): shared backbone encodes per-agent embeddings from local obs+action+agent ID, then a permutation-invariant aggregator (sum/mean/max or attention) produces a global context; the critic head(s) output either joint Q-vector or per-agent contributions q_i^m that sum (or combine) to Q_joint. Factorization and credit-assignment schemes
- Additive factorization (VDN-like): Q_joint^m ≈ Σ_i q_i^m(local_i, context). Simple, scalable, and effective for largely cooperative components of each objective.  
- Attention-based factorization (Q-attention): use cross-agent attention to compute agent contributions conditioned on preferences, enabling flexible pairwise interactions without full joint tensors.  
- Counterfactual baseline (COMA-style): critic outputs advantage A_i^m for agent i per objective to provide low-variance per-agent policy gradients while using centralized information for credit assignment.

2) Exact algorithm spec (data structures, losses, schedules)
Data structures:
- Replay: circular buffer of tuples (s_joint, a_joint, r_vector ∈ R^M, s'_joint, w_pref, head_id).
- Stratification index: map w_pref → bin b∈{1..B}.

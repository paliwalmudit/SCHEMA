Conformal Methods Lead: "Summary and next steps for methodological development and package design:

1) Validity conditions and use of OOB scores.
Conformal guarantees require exchangeability between calibration and test examples. Using out-of-bag (OOB) residuals for calibration is attractive because it reuses training data, but validity is not automatic: each OOB score must be computed from a model that did not use the corresponding example. For random-forest OOB, this condition holds at the tree level if scores are aggregated only from trees that omitted the observation. Under full-sample exchangeability, using OOB scores yields approximate marginal validity; however, dependence among OOB scores (shared trees across examples) can affect exact finite-sample guarantees. Recommendation: treat OOB-based split-conformal as empirically valid and computationally efficient, but provide rigorous alternatives (CV+ or jackknife+) as options for users needing theoretical finite-sample guarantees.

2) Choosing procedures and theoretical tradeoffs.
- Split conformal with OOB calibration: fastest, low memory, approximate validity; best when n is large.
- CV+ (cross-validation+) : retains rigorous marginal coverage under exchangeability, less biased than single-split, recommended default when runtime permits.
- Jackknife+-after-bootstrap: useful for small n, ensembles produced by bagging/bootstrap; offers strong finite-sample bounds but can be conservative if effective ensemble diversity is limited.
- Adaptive prediction sets (classification): improves efficiency by allowing variable-size sets via score normalization or class-conditional thresholds; ensure marginal vs conditional coverage distinctions and offer stratified calibration to approach class-conditional guarantees.

Coverage ≥ 1−α − δ(n_cal,ρ),
where δ(n_cal,ρ) = O( sqrt(ρ / n_cal) ). More precisely, by Dvoretzky–Kiefer–Wolfowitz applied with an “effective sample size” n_eff = n_cal/(1+(n_cal−1)ρ),

Proof sketch. Dependence inflates variance of the empirical CDF; pairwise correlation upper bound yields the n_eff expression via variance decomposition. Apply DKW (or Hoeffding) replacing n_cal by n_eff to bound quantile estimation error, which maps to coverage shortfall.

Interpretation. If trees share many common structures so ρ is not negligible, coverage degrades at rate ~sqrt(ρ/n_cal). When ρ→0 (independent OOB scores) we recover usual finite‑sample DKW bounds.

2) Randomized thinning quantitative guidance
Mechanism. Therefore δ(n_cal,ρ_t) ≈ O( sqrt(t^2 ρ0 / n_cal) ) = t · O( sqrt(ρ0 / n_cal) ). Practical rule: to halve dependence-driven error, thin trees by ~1/2; choose t by solving t ≤ (target δ) · sqrt(n_cal/ρ0). Validate ρ0 by small pilot runs.

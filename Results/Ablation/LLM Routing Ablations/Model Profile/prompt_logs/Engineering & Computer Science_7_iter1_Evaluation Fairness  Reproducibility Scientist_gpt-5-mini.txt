Consider N agents (EVs) acting in discrete time t = 1..T. Each agent i chooses action a_i(t) ∈ {0 (not charge), 1 (charge)}. The instantaneous reward for agent i when choosing a_i = 1 is r_i(t) = R(1, k(t)) + η_i(t) and for a_i = 0 is r_i(t) = R(0, k(t)) + η_i(t), where k(t)=∑_j a_j(t) is the total number charging, R(·,·) are mean rewards bounded in [0,1], and η_i(t) are zero-mean sub-Gaussian noises. R(1,k) is nonincreasing in k (congestion penalty). Agents observe only their own pulls and rewards; there is no inter-agent communication.

Algorithm (d-mab2ab-ts, formalized):
Each agent runs a Thompson Sampling (TS) instance for its two arms with independent priors (e.g., Beta priors for Bernoulli-like rewards or Gaussian priors for bounded sub-Gaussian noise). At each t agent i samples parameter θ_a from posterior for each arm a∈{0,1}, picks argmax_a E[R(a,k)|θ_a], executes action, observes reward, and updates its posterior. Optional augmentation: include a small randomization/annealing term or use sliding-window posterior updates to handle nonstationarity.

Theoretical guarantees (under explicit assumptions):
Assumptions:
1) Boundedness: rewards ∈ [0,1], noises sub-Gaussian.
2) Lipschitz coupling: |R(a,k)-R(a,k')| ≤ L |k-k'|.
3) Symmetry/homogeneity: agents identical in R and priors (for fairness results).
4) Weak coupling / contraction: the aggregate mapping from mixed-strategy distribution to expected occupancy is contractive (ensures unique mean-field fixed point).

Regret bound (per-agent, sketch):
Under the above assumptions and in the mean-field limit (N large, exchangeability), the occupancy experienced by a representative agent concentrates around a deterministic fixed point k*, making the environment effectively stationary. Using standard TS analysis for two-armed stochastic bandits, expected cumulative regret per agent after T rounds is O(log T). More precisely, for Bernoulli-like rewards with gap Δ between optimal and suboptimal arms given the fixed occupancy, E[R_T] ≤ (C/Δ) log T + o(log T), where C is constant depending on prior choices and variance. Finite-N corrections scale with O(1/√N) under concentration of k(t) around k*.

Sample complexity to reach ε-equilibrium:
To identify the mean-field equilibrium to accuracy ε with probability 1−δ requires O((L^2/ε^2) log(1/δ)) samples per agent when using empirical concentration bounds, reflecting dependence on Lipschitz constant L of the coupling.

Fairness guarantees:
With symmetric agents and identical priors, the algorithm is permutation invariant, so long-run empirical charging frequencies converge (w.h.p.) to identical values across agents in the mean-field limit. The max-min frequency gap among identical agents decays as O(1/√T) empirically and vanishes in the limit T→∞, yielding an asymptotic fairness (symmetric equilibrium) and envy-freeness for identical agents.

Limitations and necessary cautions:
If coupling is strong (non-contractive) or N is small, the occupancy process can be highly nonstationary and may break standard TS guarantees; multiple equilibria or cyclic behavior can arise. Adversarial agents or heterogeneity invalidates symmetric fairness proofs. Priors and update windows must be chosen to balance adaptivity and stability.

1) Rigorous mean-field limit proof: show propagation of chaos and transfer of single-agent TS regret bounds to the multi-agent system.

Bandit Theory Lead: "Summary of formal theory deliverables, assumptions, and near-term plan.

1) Precise model & key assumptions.
- Agents: N exchangeable agents, discrete t=1..T, actions a_i(t)∈{0,1}. Occupancy k(t)=∑_j a_j(t). Reward for i when pulling a is r_i(t)=R(a,k(t))+η_i(t), with R(a,k)∈[0,1] and η_i(t) sub-Gaussian (σ^2).  
- Technical assumptions: (A1) Lipschitz coupling: |R(a,k)-R(a,k')|≤L|k−k'|. (A2) Exchangeable i.i.d. initial posteriors. (A3) Randomized action tie-breaking (irreducibility / minorization) to avoid absorbing cycles. (A4) Contraction: mapping Φ(p) = E_k[best-response mass | population law p] is α-contractive in total variation (α<1). (A5) Bounded priors and posterior concentration (standard TS regularity).

2) Mean-field limit and propagation-of-chaos (statement).
- Lemma (Propagation of chaos, informal): Under A1–A3, as N→∞ the empirical measure μ^N_t of agent states converges (in probability, uniformly on compact t) to deterministic law μ_t solving a McKean–Vlasov recursion determined by Φ; individual agents become asymptotically independent. Proof sketch: couple the finite-N empirical process to the mean-field recursion, use Lipschitz A1 and Azuma/Hoeffding concentration to bound deviation by O(1/√N) over finite horizon; iterative contraction A4 yields uniform-in-time control.

3) Finite-N deviation & per-agent regret.
- Finite-N deviation: for fixed T, with probability 1−δ, sup_{t≤T} ||μ^N_t−μ_t||_TV ≤ C1(1/√N)√log(T/δ), constant C1(L,σ).  
- Per-agent regret: conditional on μ_t staying within ε of μ (so effective gap Δ_eff ≥ Δ_0−C2(1/√N)), TS yields expected per-agent regret R_T = O((log T)/Δ_eff) + O(T·(1/√N)√log(T/δ)). Thus asymptotic O(log T) per agent holds when N large enough that 1/√N ≪ Δ_0.

4) Effect of DP-noisy broadcasts and sliding windows (quantitative).
- DP broadcast: Gaussian mechanism adds noise Z_t∼N(0,σ_DP^2). This injects an additional occupancy estimation error of scale O(σ_DP). Finite-N deviation bound becomes O(1/√N + σ_DP). If σ_DP > O(Δ_0) the effective gap can vanish and regret may degrade (potentially linear). Composition: over T broadcasts, (ε_total,δ_total) follows advanced composition: ε_total ≈ ε_per·√{2T log(1/δ)}. Guidance: choose σ_DP so that σ_DP ≪ Δ_0 and calibrate ε via composition budget.  
- Sliding-window: using window w reduces effective sample size; TS regret scales like O((log w)/Δ_eff) per stationary epoch. If regime-change rate R_c yields ≈R_c·T change points, extra cost ≈O(R_c·w) to re-learn.

5) Feedback / identifiability conditions.
- If agent observes only own reward r_i(t) = R(a_i(t),k(t))+η, identifiability of k(t) requires that R(·,k) vary sufficiently in k (Lipschitz plus distinct values across k) and sufficient exploration so posterior distinguishes k-modes. If R is flat across a range of k, occupancy is unidentifiable: remedy by periodic noisy broadcast of k(t) or secure aggregate counts (adds identifiability and improves sample complexity by replacing σ_DP term with 1/√N).

6) Deadline-aware constraints & hybrid safety controls.
- Integrate deadlines by augmenting state with remaining energy demand and using constrained-TS: arm rewards are replaced by discounted utility that penalizes unmet energy at departure; fallback scheduler (local deadline override) guarantees service: if remaining time insufficient, force charge. 1) Contraction sufficiency (explicit lemma).
Lemma (sufficient condition for Φ to be α-contractive). Let R(a,k) be L-Lipschitz in k and suppose each agent’s soft best-response probability to prefer a=1 given occupancy k is a 1-Lipschitz function S(k) with maximal slope B (i.e. |S'(k)| ≤ B). Define Φ(p)=E_k[S(k)] with k = N·p. If L·B·N^{-1} ≤ α < 1 then Φ is α-contractive in total variation. In practice, for exchangeable agents approximate B by the logistic slope induced by Thompson-sampled posterior variance; thus a sufficient numeric test is L·B < 1 (for mean-field N→∞) and for finite N require L·B·(1/N) small. Example: if L=0.02 and B≤0.5 then α≈0.01 and contraction holds.

2) Formal identifiability Δ0 (KL / SNR).
Definition (identifiability gap Δ0). For fixed action a, let P_k denote the distribution of observed reward r when occupancy is k. Define Δ0 := min_{k≠k'} KL(P_k || P_{k'}) (KL gap) and SNR_min := min_{k≠k'} |E[P_k]-E[P_{k'}]|/σ. Effective gap used by TS is Δ_eff := Δ0 − Cmf(1/√N + σ_DP) where Cmf depends on L and posterior variance constants (see next). Empirical estimator: from historical traces cluster time steps by observed (noisy) k or approximate k via an EM/regression that treats k as latent, fit parametric P_k (Gaussian or Bernoulli), compute pairwise KLs, and take the minimum; bootstrap to produce CI.

Theorem (finite-N regret, two-arm TS, simplified explicit form). Let C0 be an O(1) constant depending on prior choice (e.g., C0≈8 for Gaussian-conjugate analysis). Define ε_N := C1·(1/√N)·√log(T/δ) where C1 = O(L/(1−α)). E[R_T] ≤ (C0/Δ_eff)·log T + T·ε_N,
where Δ_eff = Δ0 − C2·ε_N − C3·σ_DP and C2,C3 = O(1) (depend on L, prior variance). Regime condition for logarithmic per-agent regret is ε_N + σ_DP ≪ Δ0 (practically ≤ Δ0/3).

Metric definitions and aggregation rules: report both per-trial raw signals and distribution summaries. For binary outcomes (task success, unsafe output, leakage incident) report proportion, Clopper–Pearson 95% CI, and odds-ratio when comparing architectures. For calibration use Expected Calibration Error (ECE), Brier score, reliability diagrams, and report calibration per-decision threshold. For modular interactions, compute failure-transfer rates (probability that component A failure causes total task failure) and conditional recovery rates. For behavior diversity use action-distribution entropy and clustering-based failure-mode counts; validate cluster separation with silhouette scores.

Handling non-determinism and continuous evolution: run fully randomized repeated trials per scenario instance and seed all RNGs; publish per-trial seeds and traces. Present full empirical distributions and avoid single-run point estimates. For continuous pipelines, run nightly/PR-triggered regression suites and use control-chart style alerts (CUSUM) plus bootstrap-based regression detection.

Statistical tests and multiple comparisons: prefer non-parametric tests and resampling. Use permutation/bootstrapped two-sample tests for continuous metrics, Mann–Whitney U as a fallback, and Fisher exact or two-proportion tests for binary outcomes (use exact tests for small n).

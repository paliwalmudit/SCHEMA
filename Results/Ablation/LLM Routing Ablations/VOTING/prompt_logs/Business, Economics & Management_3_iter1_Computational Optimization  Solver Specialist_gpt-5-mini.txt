1) Closed-form expected-penalty and exactness condition.
- Let S be the set of enumerated failure outcomes and π_s their probabilities. For any first-stage decisions (y,s,x) the expected recourse cost (penalty + scenario transport) is
  E[penalty] = Σ_{s∈S} π_s Q(x,y,s)
  where Q(x,y,s) is the optimal value of the linear second-stage LP:
    Q(x,y,s) = min_{x_{ijs}≥0,u_{is}≥0} Σ_{i,j} c_{ij} x_{ijs} + H Σ_i u_{is}
    s.t. Σ_j x_{ijs} + u_{is} ≥ D_i  ∀i,
         Σ_i x_{ijs} ≤ (C_j + s_j) y_j · I_{j up in s}  ∀j.
- The scenario-based linearization is provably exact whenever S contains all outcomes in the support of the stochastic process and π_s are the true probabilities. In particular:
  - If independence is assumed and all 2^|F| outcomes are included with π_s = Π_{j∈failed(s)} p_j Π_{j∉failed(s)} (1-p_j), the linear reformulation is exact.
  - If we reduce S to {no-failure} ∪ {single-site failures}, the reformulation is exact only under the modeling assumption that at most one facility can fail (i.e., the true process has zero probability of multi-site failures). 1) Closed-form expected-penalty and exactness condition.
- Let S be the set of enumerated failure outcomes and π_s their probabilities. For any first-stage decisions (y,s,x) the expected recourse cost (penalty + scenario transport) is
  E[penalty] = Σ_{s∈S} π_s Q(x,y,s)
  where Q(x,y,s) is the optimal value of the linear second-stage LP:
    Q(x,y,s) = min_{x_{ijs}≥0,u_{is}≥0} Σ_{i,j} c_{ij} x_{ijs} + H Σ_i u_{is}
    s.t. Σ_j x_{ijs} + u_{is} ≥ D_i  ∀i,
         Σ_i x_{ijs} ≤ (C_j + s_j) y_j · I_{j up in s}  ∀j.
- The scenario-based linearization is provably exact whenever S contains all outcomes in the support of the stochastic process and π_s are the true probabilities. In particular:
  - If independence is assumed and all 2^|F| outcomes are included with π_s = Π_{j∈failed(s)} p_j Π_{j∉failed(s)} (1-p_j), the linear reformulation is exact.
  - If we reduce S to {no-failure} ∪ {single-site failures}, the reformulation is exact only under the modeling assumption that at most one facility can fail (i.e., the true process has zero probability of multi-site failures). When multi-failures are possible but omitted, the linear model approximates the original expectation and can be biased.

2) Modeling correlated multi-site failures (practical recipes).
- Hierarchical shock model: introduce cluster-level Bernoulli shocks (common-mode q_k) and independent residuals; generate scenarios from the induced joint law to preserve tail dependence.

3) Valid inequalities (statements + short validity argument).
- Assignment coupling: x_{ijs} ≤ D_i y_j ∀i,j,s. Valid since if y_j=0 no assignment can be made to j.

min_{y,s} Σ_j F_j y_j + Σ_j G_j s_j + E_ω[ Q(y,s;ω) ]

s.t. ∀ω,i: Σ_j x_{ij,ω} + u_{i,ω} = D_i

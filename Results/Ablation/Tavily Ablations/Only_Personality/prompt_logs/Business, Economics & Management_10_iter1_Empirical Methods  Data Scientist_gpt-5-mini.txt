Product Family Designer: "Specification for Artifact A: Reproducible Metric Definitions and Composite Modular Impact Score (MIS)

Objective
Provide explicit, reproducible formulas for per-layer modularity Qℓ, a robust null-model baseline, and a composite MIS that combines modularity with interface maturity and variability, along with default parameter values and a minimal reference implementation and unit tests.

Notation and inputs
- Layers L = {physical, information, common_parts, control, variant}. For each layer ℓ, edge weights wℓ(i,j) define interaction strength between components i and j.
- Wℓ = sum over all edges in layer ℓ of wℓ(i,j).
- Partition P partitions components into modules.
- sintraℓ = sum of wℓ(i,j) for all edges with both ends in the same module.
- Null baseline: a weighted configuration model that preserves node strengths s_i = sum_j wℓ(i,j) in layer ℓ; generate exp_intraℓ via n_null bootstrap draws.

Definitions
- Layer modularity Qℓ = (sintraℓ − exp_intraℓ) / Wℓ, with Wℓ > 0.
- Normalize Qℓ with null-distribution min_null and max_null across the n_null bootstrap draws: normalize(Qℓ) = (Qℓ − min_null) / (max_null − min_null). If max_null == min_null, set normalize(Qℓ) = 0.0.
- Interface maturity IM ∈ [0,1] and variability support VS ∈ [0,1] are provided by separate DSM annotations (consistent with the ontology).

Composite Modular Impact Score

- Outputs: MIS in [0,1], per-layer Qℓ, 95% bootstrap CI for Qℓ from nulls, and overall MIS with uncertainty bounds.

Defaults and tolerances
- Weights fixed as above; weights are configurable via a YAML/JSON config but must be reported.
- Weights on edge strengths are normalized to [0,1] before Qℓ computation.
- Bootstrap: n_null = 1000; CI at 95%.
- Tolerances: report CI width and note any degenerate Qℓ when Wℓ ≈ 0.

Minimal Python-like reference implementation (pseudo)
def compute_mis(layers, partition, IM, VS, n_null=1000, seed=None):
  rng = np.random.default_rng(seed)
  Q = {}
  for ℓ, edges in layers.items():
    W = sum(w for (_,_,w) in edges)
    sintra = sum(w for (i,j,w) in edges if partition[i] == partition[j])
    null_vals = []
    for _ in range(n_null):
      perm = rng.permutation(list(partition.values()))
      exp_intra = sum(w for (i,j,w) in edges if perm[i] == perm[j])
      null_vals.append(exp_intra / W if W>0 else 0.0)
    min_null, max_null = min(null_vals), max(null_vals)
    Qℓ = (sintra / W - np.mean(null_vals)) if W>0 else 0.0
    Q[ℓ] = (Qℓ - min_null) / (max_null - min_null) if max_null>min_null else 0.0
  wQ = 0.6 / len(layers)
  MIS = sum(wQ * Qℓ for Qℓ in Q.values()) + 0.25*IM + 0.15*VS
  MIS = min(1.0, max(0.0, MIS))
  return MIS, Q

  Q = {}
  for ℓ, edges in layers.items():
    W = sum(w for (_,_,w) in edges)
    sintra = sum(w for (i,j,w) in edges if partition[i] == partition[j])
    null_vals = []
    for _ in range(n_null):
      perm = rng.permutation(list(partition.values()))
      exp_intra = sum(w for (i,j,w) in edges if perm[i] == perm[j])
      null_vals.append(exp_intra / W if W>0 else 0.0)
    min_null, max_null = min(null_vals), max(null_vals)

  MIS = min(1.0, max(0.0, MIS))

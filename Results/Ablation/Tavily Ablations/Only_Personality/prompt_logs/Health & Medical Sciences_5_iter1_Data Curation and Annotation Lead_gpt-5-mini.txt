- Online latency/memory target: ≤40 ms/frame on a mid-range GPU (e.g., A5000), GPU memory ≤6 GB for model+memory, CPU tail <150 ms/frame.

Loss formulations and training recipe (exact)
- L_seg = 1 - Dice(p, g) where Dice(p,g) = 2 * sum(p*g) / (sum(p)+sum(g)+eps).  
- L_mem = KL(softmax(logits_curr) || softmax(logits_mem)) averaged over pixels.  
- L_wave = alpha * sum_t ||high_coeff_t||_1 + beta * sum_t ||low_coeff_t - smooth(low_coeff_{t-1})||_2^2 (sparsity + smoothness).  
- L_id = CE(ID_pred, ID_gt) + lambda_triplet * Triplet(emb_anchor, emb_pos, emb_neg) to enforce identity clustering.  
- Total loss: L = w_seg*L_seg + w_mem*L_mem + w_wave*L_wave + w_id*L_id. Defaults: w_seg=1.0, w_mem=0.5, w_wave=0.1, w_id=0.2.  
- Schedule: warmup 0–5 epochs with w_wave = 0.02 then linear to 0.1 by epoch 10; enable L_id after epoch 5. Use main LR=1e-3, weight decay 1e-4.

Identity re-linking policy (occlusion and gaps)
- Per-frame detection -> compute IoU matrix + appearance cosine between current embeddings and last-known ID embeddings.  
- Solve assignment with Hungarian using combined score = 0.6*IoU + 0.4*cosine.  
- Allow re-linking up to T_gap = 60 frames (adjust by framerate); if unmatched beyond threshold, mark ID death. New detections with confidence>0.7 create new IDs. Use memory-backed re-linking: consult long-term slot embeddings when short-term gaps occur.

Wavelet experiments and stability diagnostics

- Decomposition levels: L = 2,3,4.

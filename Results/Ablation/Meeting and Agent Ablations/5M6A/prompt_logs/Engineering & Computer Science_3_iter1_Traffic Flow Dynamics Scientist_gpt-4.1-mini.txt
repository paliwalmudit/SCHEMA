Koopman Modeling Expert: "Thanks — below I tighten the key guarantees, give explicit bounds and practical recipes you can drop into the code/CI, and include short numeric examples.

1) Explicit Lyapunov decay (α,c) with decoder Lipschitz mapping to physical units.
Let P≻0 satisfy K^T P K − P ≤ −Q with λ_min(P), λ_max(P), λ_min(Q)>0. Assume encoder/decoder are Lipschitz L_E,L_D and the latent model mismatch w_t := E(x_{t+1}) − (K z_t + B u_t) obeys ||w_t||≤ε. With V(z)=z^T P z we have
V(z_{t+1})−V(z_t) ≤ −(λ_min(Q)/λ_max(P)) V(z_t) + 2 ||K^T P|| sqrt(V(z_t)/λ_min(P)) ε + λ_max(P) ε^2.
Choose ξ = λ_min(Q)/(2 λ_max(P)). Then (by a√v ≤ ξ v + a^2/(4ξ)) we obtain the affine decay
V(z_{t+1}) − V(z_t) ≤ −α V(z_t) + c
with α = λ_min(Q)/(2 λ_max(P)) and
c = ε^2 [ λ_max(P) + (||K^T P||^2)/(λ_min(P) ξ) ].
The ultimate bound is V_∞ ≤ c/α, so the latent radius satisfies ||z−z*|| ≤ sqrt( V_∞ / λ_min(P) ). Mapping to physical space via decoder Lipschitz L_D gives
||x−x*|| ≤ L_D sqrt( c / (α λ_min(P)) ).
Numeric example: λ_min(P)=0.5, λ_max(P)=2, λ_min(Q)=0.1, ||K||≈0.98 ⇒ ||K^T P||≤1.96, ε=0.01, L_D=1.5 yields α=0.025, c≈0.03093, V_∞≈1.2373, latent radius≈1.57 and physical radius≈2.36 units. Use this template to report bounds in meters/seconds for reviewers.

2) Per‑update RLS bound ||ΔK||_2 and choosing Δ_max,ρ_max.
With standard RLS update (covariance P_t, reg/forget λ_f), innovation e_t = y_t − Φ_t^T θ_t, and feature vector φ_t:
Δθ = (P_t φ_t) e_t / (1 + φ_t^T P_t φ_t) ⇒
||Δθ||_2 ≤ ||P_t||_2 ||φ_t||_2 |e_t|.
Hence a conservative per‑update bound is Δ_max := p_max φ_max e_max where p_max = sup_t ||P_t||_2, φ_max = sup_t ||φ_t||_2, e_max is an innovation bound (use residual 99%-tile). To ensure spectral-radius safety after projection, require Δ_max ≤ margin s where s is the operator‑norm margin between current K and allowed spectral bound; if current ||K||_2 = ρ_cur and target bound ρ_max then pick s ≤ ρ_max − ρ_cur (or more conservatively s ≤ 0.5(ρ_max−ρ_cur)). After each RLS update always run projection (next section).

Numeric rule-of-thumb: if ρ_cur=0.96 and ρ_max=0.98, demand Δ_max ≤ 0.01; calibrate p_max via initialization and forgetting factor (smaller λ_f reduces p_max).

3) Blockwise SVD clipping, invariance and corrective re‑projection.
Define S = {K: K has fixed sparsity/banding pattern and ∀blocks B_i, ||B_i||_2 ≤ ρ_max}. S is closed and convex (spectral‑norm ball ∩ linear subspace). Per‑block SVD singular‑value clipping (σ←min(σ,ρ_max)) maps K into S (so it is safe). Caveat: per‑block clipping does not guarantee a global spectral_radius(K) ≤ ρ_max because inter‑block coupling can increase global radius. Corrective routine:
- Step 1: per‑block SVD clip and zero off‑band entries.
- Step 2: compute global spectral radius ρ_glob. If ρ_glob > ρ_max perform global SVD clipping (full‑matrix UΣV^T, σ←min(σ,ρ_max)) and then re‑zero off‑band entries (if this reintroduces ρ_glob>ρ_max iterate a small number of times or perform convex projection via an SDP onto S).
This guarantees K ∈ S and projection idempotence (projected matrix stays in S).

4) Latent→physical uncertainty pipeline (delta method + residuals).
At nominal z0 linearize decoder: x ≈ D(z0)+J_D(z0)(z−z0). Then
Σ_x ≈ J_D(z0) Σ_z J_D(z0)^T + Σ_res,
where Σ_res is empirical decoder residual covariance (estimate from validation set / ensemble residuals). For chance constraints on scalar output y = c^T x, use Gaussian tightening t = Φ^{-1}(1−α) sqrt(c^T Σ_x c). If Gaussianity fails, apply Cantelli: require t such that P(y−E[y]≥t) ≤ Var(y)/(Var(y)+t^2) ≤ α (solve for t). Recommendation: default = delta method (Jacobian) + empirical Σ_res; validate by QQ and empirical coverage (target ±5% error); fall back to Cantelli for safety-critical constraints.

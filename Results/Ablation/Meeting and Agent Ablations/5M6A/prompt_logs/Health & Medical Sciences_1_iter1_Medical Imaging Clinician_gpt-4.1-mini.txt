ELBO, analytic KL, and gradients (explicit)
- ELBO: L(φ,ψ,θ) = E_{qφ(r) qψ(θ)}[ log p(y | r,H,θ) ] − KL(qφ(r)||p(r)) − KL(qψ(θ)||p(θ)).  
- For qφ(r)=N(μ,Σ) and prior p(r)=N(0,K) (equivalently precision Λ): KL(q||p) = 0.5[ tr(K^{-1}Σ) + μ^T K^{-1} μ − N + ln|K| − ln|Σ| ]. Using precision Λ: KL = 0.5[ tr(Λ Σ) + μ^T Λ μ − N − ln|Λ| − ln|Σ| ]. Compute tr(Λ Σ) and Λ μ via sparse operations.  
- Gradients of KL: ∇_μ KL = K^{-1} μ = Λ μ. For Σ-parameterization via S (Σ = SS^T) use ∇_Σ KL = 0.5( K^{-1} − Σ^{-1} ) = 0.5( Λ − Σ^{-1} ). In practice we parameterize log-diagonals so ∂KL/∂logσ_i = diag(Σ) * diag(∇_Σ KL).  
- Likelihood term gradients: approximate E_q by reparameterization r = μ + S ε (ε ∼ N(0,I)) and θ = μθ + Sθ ζ; backprop through softmax(a=softmax(r/τ)) and predictor. Use multiple MC samples per bag (e.g., 1–8) and control variates if needed.

Computational complexity (summary)
- Dense kernel K: memory O(N^2), compute O(N^3) for Cholesky/inverse; impractical for N>2–5k.  
- Laplacian precision Λ (sparse): memory O(E), sparse solves O(N + E) (or ~O(N log N)) per solve; KL terms computed with sparse-matrix-vector ops O(E). Scales to large N with sparse adjacency.  
- Inducing-point GP (M inducing): training cost O(NM^2 + M^3) memory O(NM); choose M ≪ N (e.g., 50–200).  
- Low-rank Σ (rank R): storage O(NR) and ops O(NR^2), good trade-off for moderate R (10–50).

Probabilistic Modeling Lead: "Agreed plan, concrete choices, and immediate math + operational details.

Decisions for first implementation
- Prior: Laplacian precision form p(r) ∝ exp(−(λ/2) r^T L r) with small jitter δI so Λ = λL + δI (sparse, scalable, encodes spatial/feature adjacency). This gives K = Λ^{-1} but we work with Λ for efficiency.  
- Variational posterior qφ(r|H): amortized Gaussian with mean μφ(H) and diagonal covariance Σφ(H) for prototype (O(N) params). Add option to upgrade to low-rank Σ = D + UU^T (rank R) in later ablations.  
- Inducing points: start with global/shared inducing scheme only if we switch to GP kernel K; for Laplacian we use graph construction per-bag (sparse adjacency). Shared inducing points add consistency but increase bookkeeping; defer to second stage.

ELBO, analytic KL, and gradients (explicit)
- ELBO: L(φ,ψ,θ) = E_{qφ(r) qψ(θ)}[ log p(y | r,H,θ) ] − KL(qφ(r)||p(r)) − KL(qψ(θ)||p(θ)).  
- For qφ(r)=N(μ,Σ) and prior p(r)=N(0,K) (equivalently precision Λ): KL(q||p) = 0.5[ tr(K^{-1}Σ) + μ^T K^{-1} μ − N + ln|K| − ln|Σ| ]. Using precision Λ: KL = 0.5[ tr(Λ Σ) + μ^T Λ μ − N − ln|Λ| − ln|Σ| ]. Compute tr(Λ Σ) and Λ μ via sparse operations.  
- Gradients of KL: ∇_μ KL = K^{-1} μ = Λ μ. For Σ-parameterization via S (Σ = SS^T) use ∇_Σ KL = 0.5( K^{-1} − Σ^{-1} ) = 0.5( Λ − Σ^{-1} ). In practice we parameterize log-diagonals so ∂KL/∂logσ_i = diag(Σ) * diag(∇_Σ KL).  
- Likelihood term gradients: approximate E_q by reparameterization r = μ + S ε (ε ∼ N(0,I)) and θ = μθ + Sθ ζ; backprop through softmax(a=softmax(r/τ)) and predictor. Use multiple MC samples per bag (e.g., 1–8) and control variates if needed.

Computational complexity (summary)
- Dense kernel K: memory O(N^2), compute O(N^3) for Cholesky/inverse; impractical for N>2–5k.  
- Laplacian precision Λ (sparse): memory O(E), sparse solves O(N + E) (or ~O(N log N)) per solve; KL terms computed with sparse-matrix-vector ops O(E). Scales to large N with sparse adjacency.  
- Inducing-point GP (M inducing): training cost O(NM^2 + M^3) memory O(NM); choose M ≪ N (e.g., 50–200).  
- Low-rank Σ (rank R): storage O(NR) and ops O(NR^2), good trade-off for moderate R (10–50).

Practical identifiability & stability
- Enforce zero-mean constraint by penalizing (1^T μ)^2 or parametrize μ as μ̃ − mean(μ̃). Place a weak prior on scale (λ or τ) and clamp τ in [τ_min, τ_max] (e.g., [0.02,1.0]); warm up KL (β-annealing) to avoid posterior collapse. Initialize μ with deterministic attention logits (small MLP) and diag Σ to small values (e.g., variance 1e-2).

Posterior covariance choices (rationale)
- Start diagonal for compute and stability; move to low-rank when instance correlations are critical (spatially contiguous lesions). Low-rank captures dominant covariance modes with modest cost; full dense Σ only for small bags or diagnostics.

OOD, uncertainty, and attention validation
- OOD metrics: AUROC (OOD detection via predictive entropy), Brier, NLL, ECE, and calibration under synthetic covariate shifts. Attention validation: compare attention-derived masks to sparse expert labels with IoU/Dice; test significance with permutation tests and report bootstrap CIs.

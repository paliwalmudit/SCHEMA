Incorporate RoB into weighting via two routes: (a) frequentist sensitivity (exclude/highlight high‑risk studies) and (b) Bayesian bias‑adjusted models that apply RoB‑informed bias priors pulling high/critical RoB effects toward the null. Apply a GRADE‑like mapping: RCTs start high, observational start low; downgrade one level for serious RoB, two for critical RoB, and further downgrade for inconsistency, indirectness, imprecision, or suspected publication bias; upgrade only for large, robust effects with strong confounding control. Record all judgments in a RoB→GRADE audit sheet.

Selection‑model and publication‑bias toolkit: primary diagnostics use metafor::regtest (Egger) and PET‑PEESE via metafor::rma (run PET‑PEESE only if k ≥ 15). For selection models on independent effects use weightr::weightfunct (weightr) and metafor::trimfill only as sensitivity. For dependent/multi‑arm data prefer Bayesian selection modelling in brms or rstan where the selection process and within‑study covariance can be explicitly modelled; use robumeta::robu and clubSandwich::coef_test(vcovCR="CR2", test="Satterthwaite") for RVE with Tipton corrections when k is small.

Heterogeneity thresholds and rules: use I2 bands <25% low, 25–50% moderate, 50–75% substantial, >75% considerable; flag tau2 <0.05 low, 0.05–0.20 moderate, >0.20 large (on standardized/r scale). Decision rules: if I2 ≥ 75% or 95% prediction interval crosses both meaningful benefit and harm after prespecified moderators, avoid a single pooled summary and report stratified or narrative syntheses; if prespecified moderators explain ≥50% of tau2 report moderator‑adjusted pooled estimates.

Cluster, multi‑arm, and dependent TTE handling: prefer author‑reported cluster‑adjusted estimates; otherwise inflate variances by DE = 1 + (m̄−1)*ICC using reported or plausible ICC and test ±0.05 sensitivity. For multi‑arm trials either combine arms per Cochrane or model correlated contrasts in metafor::rma.mv supplying within‑study covariances; if covariances unavailable use RVE clustering by study. For multiple correlated HRs extract log‑HR and variance, use multivariate rma.mv with approximated covariances or Bayesian multivariate survival models; apply cluster‑adjusted HRs when provided.

Conversion of adjusted estimates: convert OR/HR → d via d = ln(OR)*√3/π and then r = d/√(d^2+4); convert standardized β → r only for simple/minimally adjusted models (≤2 covariates) using Peterson & Brown r ≈ 0.98β + 0.05 and only for |β| in [0.05,0.50]; flag all converted_* values. Exclude heavily adjusted estimates (propensity‑score, >2 covariates, stepwise/selected models) from primary pooled estimates and analyze them separately; include propensity‑score adjusted estimates only when balance diagnostics or IPD permit credible back‑transformation.

Missing SDs/variances and sensitivity: back‑calculate from SEs, CIs, p‑values when possible; otherwise impute SD from pooled SD of similar studies or use multilevel multiple imputation (mice with pan/2l methods) with m ≥ 20 and relevant auxiliaries. Prespecified sensitivity analyses: (a) alternative SD ±25%, (b) complete‑case analysis, and (c) impact on tau2 and pooled estimates; always report percent imputed.

Metadata, licensing, CI/CD and reproducibility: adopt DataCite metadata schema; publish de‑identified derivatives, codebook, and scripts under CC‑BY; place sensitive extracts under controlled access with DUA. Use GitHub Actions for CI (R CMD CHECK, testthat unit tests for conversion functions), Docker (rocker/verse:4.2.2) with exact package versions, and push images to GitHub Packages/Docker Hub.

2‑week pilot owners, deadlines, and success criteria: Week 1 (Days 1–7) — Data Extraction & Coding Specialist: deliver extraction template, codebook pages, 30‑study calibration set (due Day 5); Meta‑Analysis Statistician: deliver Dockerfile, R scripts for conversions and ρ estimation (due Day 7); Systematic Review Methodologist: deliver RoB→GRADE spreadsheet (due Day 5). Success = Docker builds, unit tests pass, templates accepted. Week 2 (Days 8–14) — Coders: double‑code calibration set and deliver coder reliability report (κ ≥ 0.70, ICC ≥ 0.75); Meta‑Analysis Statistician: produce mini‑meta with ρ sensitivity plots and conversion accuracy ≥90% vs author r (due Day 14). Success = reliability thresholds met, mini‑meta runs without errors, pilot report delivered for registration.

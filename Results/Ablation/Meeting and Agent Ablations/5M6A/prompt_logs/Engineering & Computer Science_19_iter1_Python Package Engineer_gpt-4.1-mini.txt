Conformal Prediction Theorist: "Below I give concise theorem sketches, practical prescriptions, and concrete defaults needed to make CoverForest’s claims reproducible and defensible. References: Vovk et al. (2005) for basic conformal theory, Lei et al. (2018) for split conformal finite‑sample guarantees, Romano et al. (2019) (CQR) for distributional/quantile conformal ideas, Barber et al. (2021) for jackknife+/CV+ guarantees, and the survey/tutorial by Angelopoulos & Bates (2021) for recent extensions (see these works for formal proofs).

1) Finite‑sample theorem sketches and assumptions.
- Split (inductive) conformal (Lei et al. 2018): Assume calibration and test examples are exchangeable. Let n_cal be calibration size and q̂ the empirical (⌈(1−α)(n_cal+1)⌉)-th quantile of nonconformity scores on calibration. Then for a new exchangeable test point X: P(Y ∈ C(X)) ≥ 1 − α (exact finite‑sample marginal coverage). Key assumption: exchangeability of calibration and test data and that calibration scores do not depend on test label.
- Mondrian (cellwise) conformal: Given a measurable partition M(X) of feature space defined without using calibration labels, apply split conformal within each cell with n_cal(m) calibration points in cell m. Then for any cell with n_cal(m)>0, P(Y ∈ C(X) | M(X)=m) ≥ 1−α (finite‑sample cellwise validity). Practical requirement: partitions must be defined prior to seeing calibration labels and cells must have sufficient n_cal(m).
- Weighted conformal under covariate shift: If true importance weights w(x)=dP_test/dP_cal are known, replacing empirical quantile by the weighted empirical quantile yields weighted coverage validity under exchangeability after reweighting. In practice, validity is approximate and requires consistent, bounded weight estimates; see literature on conformal under covariate shift and Angelopoulos & Bates for details.
- Jackknife+/CV+: Under exchangeability, jackknife+ (Barber et al.) gives provable marginal coverage bounds (conservative): coverage ≥ 1−2α in the worst case for certain intervals, with tighter bounds under additional symmetry. CV+ empirically tightens intervals; these require retraining/folding and are computationally heavier but avoid a dedicated calibration split.

2) Density‑ratio estimators, regularization, ESS heuristics.
- Candidate estimators: probabilistic classifier (train logistic/Forest to discriminate test vs calibration), uLSIF/KLIEP (direct ratio estimators), and KMM (kernel mean matching). Practical defaults: start with a probabilistic classifier for robustness and uLSIF as a second option for low‑dimensional continuous X.
- Stabilization heuristics: normalize weights to sum to n_cal, truncate weights at a cap B (suggest B = median(w) + 10·IQR or hard cap at 99th percentile) and optionally add small ridge (w := w/(w + ε)).
- ESS diagnostics: ESS := (sum w)^2 / sum w^2. Recommendation: ESS ≥ 200 for reliable weighted conformal; flag ESS < 100 as high‑risk and ESS between 100–200 as cautionary. Empirical sensitivity checks should be run if ESS is low.

3) Mondrian partition algorithm (summary pseudocode + defaults).
- Build RF on training data (structure only). For each tree, record leaf ids for calibration points and test points. Define initial cells as the set of unique leaf signatures across forest (or use majority-vote leaf assignment).
- Merge small cells: while any cell size < min_cell (default min_cell = 30–50), merge each small cell with nearest neighbor cell in feature‑space (e.g., by centroid distance) or merge into parent leaf level until size ≥ min_cell.
- Map new X to cell: use the same tree leaf mapping and resolved merged-cell mapping.
- Default: min_cal_per_cell = 40; if many cells still small, fallback to coarser partition (fewer trees, shallower leaves) or pooled conformal.

4) RF honesty and implementation defaults.
- For asymptotic/local guarantees use honest trees: for each tree, randomly split its bootstrap/subsample into structure and estimation halves; grow splits on structure, estimate leaf predictions on estimation. Use subsampling without replacement (subsample fraction 0.5), n_estimators = 500, min_samples_leaf = 5–20 (default 10).
- Implementation: sklearn does not natively support honesty; implement honesty wrapper that samples per-tree structure/estimation indices (or use grf-style implementations). Set bootstrap=False and max_samples=subsample to enforce subsampling.

5) Jackknife+/CV+ trade‑offs.
- Guarantees: jackknife+ gives conservative finite‑sample coverage (worst‑case ≥ 1−2α) and often near nominal in practice; CV+ often yields tighter intervals but requires k model refits. Cost: roughly k× training time for CV+; jackknife+ (leave‑one‑out style) can be O(n) fits but can be approximated with efficient retraining or influence‑function approaches.

6) Complexity, defaults, diagnostics & API.
- Complexity: RF train O(T · n_train · log n_train · d); calibration quantile O(n_cal log n_cal). CV+/jackknife+ multiply training cost by folds. Memory: store O(n · T) leaf assignments if using Mondrian.
- Defaults: n_estimators=500, subsample=0.5, min_samples_leaf=10, calibration_fraction=0.2.
- Per‑instance diagnostics to return: ESS, weight_variance, calibration_cell_size, OOB_dependence (fraction of calibration points sharing many trees/leaf with test point). Flagging thresholds: ESS<200, weight_var>0.1, cell_size<40, OOB_dependence>0.5.
- API sketch: class CoverForest(...); fit(X_train,y_train, X_cal=None,y_cal=None, method='split', alpha=0.1, rf_params=None, weight_estimator=None, mondrian_params=None, random_state=None). predict_interval(X_test, return_diagnostics=True) -> (intervals, diagnostics_dict). Include reproducibility hooks: random_state and exportable manifest (commit hash, package versions, seed).

1) Finite‑sample coverage decomposition (practical bound).
For CoverForest (honest RF + weighted conformal) write coverage error as three terms:
P(Y_{n+1} ∉ C) − α ≤ Bias_w + SampErr + Leak,
where (with probability ≥1−δ):
- Bias_w ≤ ||ŵ_n/Z_n − w*||_1 (L1 bias of normalized weights) controls systematic shift from true importance;
- SampErr ≈ sqrt( log(2/δ) / (2 · ESS) ) (DKW‑style sampling error for the weighted empirical CDF), with ESS := (∑ ŵ_i)^2/∑ ŵ_i^2;
- Leak = fraction of calibration/test predictions that used their own label (zero when honesty/OOB enforced).
Consequence: for finite n_cal, achieving nominal coverage requires small weight bias and sufficiently large ESS; explicitly control both terms in diagnostics and selection.

2) Asymptotic rates for ŵ_n.
Asymptotic 1−α coverage holds if ŵ_n normalized converges uniformly: sup_x |ŵ_n/Z_n − w*(x)| = o_p(1) and ESS → ∞. In practice L1 consistency (||ŵ_n−w*||_1 = o_p(1)) plus ESS = ω(1) suffices; stronger sup‑norm convergence yields faster finite‑sample control. If only L2 convergence is available, combine with boundedness assumptions to translate L2→L1 via support size; otherwise add explicit finite corrections.

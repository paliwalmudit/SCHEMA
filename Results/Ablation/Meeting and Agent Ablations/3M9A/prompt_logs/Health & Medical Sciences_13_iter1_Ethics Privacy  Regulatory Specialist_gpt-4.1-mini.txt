3) Effect-size harmonization (algebraic rules + R snippet)
- Convert to r (then Fisher z):  
  - Standardized beta (b*) from simple bivariate regression: r ≈ b*. Variance of z: var(z)=1/(n-3).  
  - Odds ratio (OR): d = ln(OR) * sqrt(3)/π ; r = d / sqrt(d^2 + 4).  
  - Hazard ratio (HR): approximate via ln(HR)→d using d = ln(HR) * sqrt(6)/π (preregistered approximant); r = d / sqrt(d^2 + 4).  
  - Mean difference (Cohen’s d): d = (M1−M2)/SD_pooled ; r = d / sqrt(d^2 + 4).  
  - After r → Fisher z: z = atanh(r); var(z)=1/(n-3) (or computed from reported SEs when available).  
- R snippet (illustrative):  
  - library(metafor); d <- log(OR)*sqrt(3)/pi; r <- d/sqrt(d^2+4); z <- atanh(r); varz <- 1/(n-3).  
  - For raw counts use escalc(measure="OR", ai, bi, ci, di, data=dat).

4) Multiple effects per study: priority and modeling rules
- Priority selection: prefer validated multi-item measures over single-item, longest follow-up for longitudinal, objective use > self-report, larger effective N if mutually exclusive. If multiple non-redundant effects remain, retain all and model dependence.  
- Modeling: if within-study covariances known use mvmeta::mvmeta or metaSEM::metaSEM; if covariances unknown but multiple effects per study use metafor::rma.mv(yi, vi, random=~1|study/effect) with clubSandwich::coef_test for robust SEs; for small-study clusters use robumeta::robu or clubSandwich corrections.

5) Missing variances/imputation plan
- Number imputations m = 20 (MICE, predictive mean matching). Predictors: sample size, reported SE/CIs, outcome type, study design, IoT category, era, Q_i_norm. Diagnostics: trace plots, distribution overlap, compare pooled estimates across imputations; pool with Rubin’s rules. Accept imputation if ≤30% studies in a predictor-outcome cluster require imputation; primary analyses exclude imputed variances, secondary analyses include them.

6) Publication-bias & small-study effects
- Tests preregistered: Egger (metafor::regtest), PET-PEESE (metafor::rma with sei predictor), trim-and-fill (metafor::trimfill secondary), selection models (weightr::weightfunct), p-curve/p-uniform as sensitivity. Interpretation: report unadjusted + adjusted; flag results as sensitive if adjusted pooled estimate outside original 95%CI or sign changes.

7) Non-independence decision tree & exact functions
- Single effect/study: metafor::rma.uni. Multiple dependent effects, known covariances: mvmeta::mvmeta or metaSEM::metaSEM.

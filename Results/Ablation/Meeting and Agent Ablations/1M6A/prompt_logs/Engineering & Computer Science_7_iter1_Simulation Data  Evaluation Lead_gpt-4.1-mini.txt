Agents communicate only with neighbors in a fixed communication graph G (possibly time-varying) under bandwidth/energy constraints. The decentralized objective is to minimize network regret
R(T) = E[ sum_{t=1}^T (OPT_t - sum_{i=1}^N r_{A_i(t)} ) ],
where OPT_t is the expected reward of the best feasible allocation at time t (given capacities).

Modeling choices and assumptions:
- Stochastic stationary rewards with gaps Δ_k between arms (can be extended to nonstationary/adversarial).
- Collision model: either hard collisions (zero reward when >c_k agents select arm k) or capacity-limited reward sharing.
- Communication model: synchronous rounds or asynchronous gossip; graph spectral gap 1-λ governs mixing.

Algorithmic proposals:
1) Gossip-UCB (for capacity-aware multi-play): each agent runs local UCB estimates for each arm, periodically averages empirical counts/rewards with neighbors using weighted consensus, and then resolves local selections via a distributed matching/reservation protocol ensuring capacity constraints (e.g., randomized tie-breaking with reservation tokens). 3) Federated Multi-Play UCB (FedMP-UCB): agents aggregate gradients/statistics to a sparse overlay (or leader election) infrequently to reduce messaging; leader broadcasts top-C_k arms per cluster.

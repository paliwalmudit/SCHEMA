Summary and formal problem statement:
Consider N electric vehicles (agents) repeatedly selecting among K charging options (arms) over horizon T. Arm k has an unknown reward distribution r_k(x, t) representing charging utility (depends on agent type x, time t) and a capacity c_k (max concurrent chargers) that induces congestion/collision effects. At each round t each agent i picks arm A_i(t) and observes a (possibly delayed/noisy) reward Y_i(t) and limited feedback about collisions. Agents communicate only with neighbors in a fixed communication graph G (possibly time-varying) under bandwidth/energy constraints. The decentralized objective is to minimize network regret
R(T) = E[ sum_{t=1}^T (OPT_t - sum_{i=1}^N r_{A_i(t)} ) ],
where OPT_t is the expected reward of the best feasible allocation at time t (given capacities).

Modeling choices and assumptions:
- Stochastic stationary rewards with gaps Δ_k between arms (can be extended to nonstationary/adversarial).
- Collision model: either hard collisions (zero reward when >c_k agents select arm k) or capacity-limited reward sharing.
- Communication model: synchronous rounds or asynchronous gossip; graph spectral gap 1-λ governs mixing.

Algorithmic proposals:
1) Gossip-UCB (for capacity-aware multi-play): each agent runs local UCB estimates for each arm, periodically averages empirical counts/rewards with neighbors using weighted consensus, and then resolves local selections via a distributed matching/reservation protocol ensuring capacity constraints (e.g., randomized tie-breaking with reservation tokens). Communication is event-triggered: share only when local estimate changes exceed thresholds.
2) Collision-Aware Decentralized UCB (CA-DUCB): agents maintain indices that include collision penalties, learn effective reward per-capacity, and use implicit coordination via randomized delays to reduce simultaneous pulls.
3) Federated Multi-Play UCB (FedMP-UCB): agents aggregate gradients/statistics to a sparse overlay (or leader election) infrequently to reduce messaging; leader broadcasts top-C_k arms per cluster.

Theoretical guarantees (sketch):
Under standard stochastic assumptions and connected graph with spectral gap 1-λ, Gossip-UCB achieves network regret
R(T) = O( sum_{k: suboptimal} ( (N log T)/Δ_k ) + ( N log T /(1-λ) ) ),
where the first term is the learning term across agents and the second captures consensus/communication error. With event-triggered communication, the additional communication-induced regret can be made an additive O( log T ) factor while reducing messages to O(log T) per agent. For multi-play (capacitated) arms the leading term scales as O( sum_k ( (log T)/Δ_k ) ) independent of naive collision multiplicity because learning is shared.

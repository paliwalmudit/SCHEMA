Change-detection algorithm (high level)
1. Compute file/content changes S_files = {v | fingerprint(inputs(v)) changed}.
2. Compute config diff D = diff(cfg_old,cfg_new).
3. Compute S_cfg = {v | π_v(D) ≠ ∅} — nodes whose declared config fragment intersects D.
4. Seed S0 = S_files ∪ S_cfg.
5. Compute affected set A = transitive-closure_forward(S0) over G (i.e., all nodes reachable from S0).
6. For each v ∈ A recompute K(v); if cache contains artifact for K(v) skip execution, else schedule v for execution following topological order.

Correctness and minimality
- Soundness: If all declared inputs (including π_v(cfg) and toolchain fingerprint) and hermetic execution hold, any cached artifact returned by matching K(v) is semantically valid because K(v) is collision-resistant and includes all influencing inputs.
